# Off-Context GRPO: Learning to Reason on Hard Problems using Privileged Information

**arXiv**: 2607.19313 | **GitHub**: https://github.com/AgPriyank/OC-GRPO | **机构**: Meta AI + Columbia University

---

## 一句话总结

OC-GRPO 通过引入受权限信息（解题前缀/hint）引导重抽样并配合重要性权重校正，在几乎零额外计算成本下解决了 GRPO 在难题上的零增益问题（learning cliff），在数学推理基准上平均提升 3.9% 绝对精度（13.8% 相对提升）。

## 问题背景

GRPO 是目前 RLVR（Reinforcement Learning with Verifiable Rewards）的主流算法，但它完全依赖于同一组内抽样结果的奖励方差来产生更新信号。当所有抽样结果都错误时——这在难题上极其常见——方差为零，梯度完全消失，模型学不到任何东西。这种“学习悬崖”是当前 RLVR 技术的核心矛盾：难题正是最需要学习的地方，但学习信号却偏偏在难题上消失。

## 核心方法

1. **受权限引导重抽样（Guided Rollouts）**：在训练时向 prompt 中注入解题前缀或 hint（如“试试用反证法”），使模型能生成正确结果，打破零增益困局。
2. **“脱上下文”问题（Off-Context Problem）诊断**：直接使用受引导 prompt 产生的抽样结果计算梯度会导致目标不匹配，因为推理时并没有这些引导信息——作者首次明确指出这一问题。
3. **重要性权重校正（Importance-Weighted Correction）**：OC-GRPO 的核心创新是使用一个新的重要性权重 ρ_i^oc(θ) = π_θ(y_i|x) / π_θ当(y_i|g(x))，分子用原始 prompt（x）计算，分母用受引导 prompt（g(x)）计算，从而将更新方向向回扭转到原始目标。
4. **最小修改**：仅修改 GRPO 的重要性权重计算部分，不需要额外的模型组件、奖励形状或混合目标，实现极其简洁。

## 亮点

1. **直击痛点**：GRPO 的零增益问题是当前少有人系统性解决的，大多数工作只在简单问题上测试而回避了难题。
2. **简洁有效**：包装为一个重要性权重的修改，不需要 SFT/奖励形状/模型组件，很容易集成到现有 GRPO 工具链中。
3. **完整开源**：包括训练数据、配置、评估脚本、veRL 分支，复现成本极低。
4. **理论清晰**：首次明确定义“Off-Context Problem”，为后续工作提供了理论框架。

## 局限

1. 实验仅聚焦于数学推理基准（MATH/AIME 等），尚未验证在普遍代理任务（如 SWE-bench、WebShop）上的效果。
2. 引导信息（解题前缀/hint）的自动生成方法尚未探讨，目前依赖于现有解题数据。
3. 对于极端难题（即使有引导信息也干不出正确结果的问题），方法仍然无效。

## 个人评价

这篇论文对我最大的启发是“简单的问题不一定需要复杂的解决方案”。在前一阶段的工作中（如 PATR、CompactionRL、3SPO），大家都在设计复杂的算法来优化代理 RL ，而 OC-GRPO 只用一个重要性权重就解决了这个基础问题。这也让我想到，在我们的 GWS 研究中，是否也有这样的“简单但未解决的核心问题”值得深入？

另外，OC-GRPO 的完整开源复现包也很值得学习——包含训练数据、verl 分支、配置文件、评估脚本，到位的复现性设计。如果我们后续要开源 GWS 代码，这是一个很好的参考格式。
