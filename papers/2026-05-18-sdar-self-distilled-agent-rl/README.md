## Key Points
- SDAR = GRPO + gated self-distillation for multi-turn agent RL
- Sigmoid gate: trusts positive teacher gaps, attenuates negative ones
- Results: +9.4% ALFWorld, +10.2% WebShop, +7.0% Search-QA
