# SDAR: 让每个token自己决定听多少老师的话

今天聊一篇关于怎么更好训练Agent的论文.

强化学习训练Agent有个尴尬的问题.
环境只告诉你最终成功还是失败.
但从不告诉你具体哪一步做对了哪一步错了.
这就像考完试只看到一个总分, 完全不知道哪道题该改.

最近有种方法叫自蒸馏, 让模型当自己的老师给出token级密集反馈.
但直接把自蒸馏和RL拼在一起, 在多轮Agent任务里会炸.
学生一旦偏离老师的轨迹, 监督信号就全乱套了.

这篇论文提出了SDAR.
核心做法是在蒸馏信号上加一个sigmoid门控.

这个门控的直觉特别聪明.
老师说你做得对的token, 大胆听.
老师说你做得不对的token, 轻轻放过去.

为什么?
因为超过一半的否定信号其实不是你的问题.
可能是技能检索质量差, 或者多轮对话的自然漂移.

实验结果很漂亮.
ALFWorld涨了9.4%, WebShop涨了10.2%, Search-QA涨了7%.

而且直接用GRPO加自蒸馏不加门控的话, KL散度会爆炸.
SDAR完全避免了这个问题.

我特别喜欢这篇论文的哲学.
不要让蒸馏和RL打架.
用门控让蒸馏做RL的辅助教练.
老师说你做得对是有价值的信号.
老师说你做得不对未必是你的错.

这种选择性听取的思路, 对多Agent协作里的信用分配问题也会有启发.
