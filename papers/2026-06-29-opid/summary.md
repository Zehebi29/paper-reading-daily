# OPID: On-Policy Skill Distillation for Agentic Reinforcement Learning

**arXiv**: 2606.26790 | **GitHub**: https://github.com/jinyangwu/OPID | **机构**: 中科院自动化所 / 未知

---

## 一句话总结

OPID 从已完成的 on-policy 轨迹中提取层次化技能（场景级 + 步骤级），通过自蒸馏优势结合结果优势来密集训练 agent RL，在 ALFWorld/WebShop/SearchQA 上显著提升性能、样本效率和鲁棒性。

## 问题背景

基于结果的强化学习（outcome-based RL）提供了稳定的优化框架，但稀疏的轨迹级奖励无法指导中间步骤的决策。现有的 on-policy 自蒸馏技术借助外部技能存储，但维护成本高、可能与当前策略的状态分布不匹配，限制了实际效果。

## 核心方法

1. **层次化技能表示**：将轨迹后视分为两层——场景级技能（全局工作流/失败规避规则）和步骤级技能（关键时刻的局部决策知识）。
2. **Critical-First 路由机制**：当检测到关键决策时使用步骤级技能，否则回退到场景级技能作为默认指导。
3. **自蒸馏优势计算**：将技能注入交互历史，老策略在原始和技能增强两种上下文下重新评分同一样本，得到 token 级自蒸馏优势。
4. **双重优势结合**：将 token 级自蒸馏优势与轨迹级结果优势相结合，既保持 RL 作主体目标，又引入密集、分布匹配的后视监督信号。

## 关键结果

| 实验环境 | 主要结果 |
|:---|:---|
| ALFWorld | OPID 显著提升了任务成功率、样本效率和鲁棒性，超过 outcome-only RL 和现有 skill-distillation 基线 |
| WebShop | 同样取得了显著提升，尤其在样本效率方面 |
| Search-based QA | 表现优于所有对比方法，展示了良好的泛化能力 |

*（请注意：论文未提供精确数字百分比，以“显著提升”等性质描述为主）*

## 亮点

1. 不依赖外部技能存储或特权上下文，完全基于 on-policy 轨迹提取技能监督，降低了维护成本。
2. 层次化技能 + critical-first 路由是巧妙的设计，既能提供密集监督又避免了不必要的技能注入。
3. 自蒸馏优势与结果优势的组合既保持了 RL 的稳定性，又引入了密集 token 级信号。
4. GitHub 仓库已开源（44 stars, Python），且在积极更新中。

## 局限

1. 论文缺乏精确的数值结果表（如成功率百分比），以性质描述为主，难以做精确对比。
2. 仅在三个环境上验证，泛化到更复杂的现实任务（如代码生成、工具使用）的效果尚待验证。
3. 技能提取的质量很大程度依赖于样本轨迹的质量，在极度稀疏奖励的任务中可能提取到有偏差的技能。

## 个人评价

这篇工作解决了一个很实际的问题：如何在不依赖外部存储的情况下为 agent RL 提供密集 token 级监督。OPID 的核心设计——层次化技能 + critical-first 路由 + 自蒸馏优势——很巧妙，尤其是 critical-first 路由让技能注入更精准，避免了每步都注入的噪音。对我们的 GWS 项目来说，这种从已完成轨迹中提取技能监督的思路很值得借鉴——焊缝规划中的成功/失败轨迹同样可以提取出层次化的规划技能。
