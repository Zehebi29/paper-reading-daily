# ECHO: Prune to Act, Trace to Learn with Selective Turn Memory in Agentic RL

**arXiv**: 2606.31650 | **GitHub**: https://github.com/xiezijun714-lang/Echo | **机构**: 北京大学数学学院 + 百度

---

## 一句话总结

ECHO 提出了一种选择性轮次记忆框架，通过源索引的上下文重构和可追溯信用分配，同时解决了长距离 Agent RL 中的历史瘦化和信用分配模糊两大问题，在 BrowseComp-Plus 上 ECHO 以43.4% 显著领先 GRPO (28.9%) 和 SUPO (36.1%)。

## 问题背景

长距离语言 agent 在工具交互时受限于有界上下文窗口，现有方法（截断、摘要、压缩）虽然让长轮次可行，但引入了两个耦合问题：(1) 历史观察被剔除或压缩，细粒度证据难以复用；(2) 原始轮次失去源地址能力，结果驱动的 RL 无法将更新对准到支撑成功答案的证据轮次。

## 核心方法

- **源索引记忆储存**：每个完成的环境交互轮次被压缩为尺寸约定的记忆记录（包含"发现"总结），与源索引一起储存
- **可追溯上下文重构**：通过学习的选择机制从之前的记忆中选取相关记录，重建有界上下文，代替 static 语义 top-k 检索
- **记忆选择动作**：每次之前也作为动作产生，可以被 RL 优化，而非硬编码策略
- **可追溯信用分配**：重新利用被选择的源索引，将积极结果信用路由到支撑成功答案的证据轮次和选择动作，避免将奖励均匀分配给所有 token

## 关键结果

| 指标 | ECHO | GRPO | SUPO (滚动摘要) |
|:---|:---:|:---:|:---:|
| BrowseComp-Plus (held-out acc) | **43.4%** | 28.9% | 36.1% |
| 零样本广化平均 (Qwen3-32B) | **40.2%** | 33.6% | 34.8% |
| 零样本广化平均 (MoE Qwen3-30B) | **30.5%** | 25.9% | 26.9% |
| 平均轮次数 | 仅略高于 GRPO | 最低 (11.2) | 最高 (45.3) |
| 轨迹体积 | 低于 SUPO | 最低 | 最高 |

## 亮点

- **恐怖的提升幅度**：BrowseComp-Plus 上 14.5pp 领先 GRPO，这在难度极高的多轮搜索问答基准上非常惊人
- **零样本广化能力强**：从 BrowseComp-Plus 训练的策略可广化到多目标 QA、代码生成、多源信息搜索等多个领域
- **轮次和体积双优化**：不像 SUPO 那样靠熔断增加产生来提升准确率，而是高效利用已有信息
- **完整开源**：GitHub 仓库 Apache-2.0 许可，数据、代码、模型全开放

## 局限

- 仅在 BrowseComp-Plus 上进行了主要训练评估，更多基准的直接对比有待扩展
- 记忆选择策略的训练开销较高（需要 RL 优化选择动作）
- 数据集大小较小（747 训练例），是否能在更大规模的数据集上维持优势不明

## 个人评价

这篇论文解决的问题很实际。长距离 Agent RL 的两个痛点——历史丢失和信用模糊——被耦合在一起解决，而不是分开对待，这是很聪明的设计。特别是记忆选择动作本身被当作动作空间的一部分进行 RL 优化，这个思路和当前的“学习如何学习”趋势一致。

从结果来看，+14.5pp 的提升幅度说明这个问题的重要性被低估了。对我们的 GWS 项目来说，如果需要解决多步骤点位规划中的历史参考问题，ECHO 的源索引重构思想值得借鉴。
