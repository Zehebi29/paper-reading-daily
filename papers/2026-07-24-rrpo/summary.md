# RRPO: Reference-Relative Policy Optimization with Stratified Conditional Rollouts

**arXiv**: 2607.18470 | **GitHub**: 无 | **机构**: UCSD + Adobe Research

---

## 一句话总结

RRPO 提出了一种通过参考相对对比学习来替代 GRPO 中基于可验证信号的 advantage 构建的方法，使得组相对策略优化可以应用于不具备明确 ground-truth verifier 的场景，在 GSM8K/对话摘要/长文本生成上表现与基于 verifier 的方法持平或更优。

## 问题背景

GRPO 在可验证反馈（如数学题目答案匹配）上效果显著，但它的 advantage 构建依赖于任务提供的正确性信号（如 0/1 正确标签）。然而许多现实场景（如对话摘要、长文本解释生成）不具备单一的正确性判断标准，这限制了 GRPO 的通用性。如何将组相对优化扩展到非可验证场景是一个关键问题。

## 核心方法

1. **Stratified Conditional Rollouts**: 用条件生成的方式构建正负锚点集（anchor sets）——对同一个 prompt 分别用“强条件”和“弱条件”生成高质量和低质量的回答作为参考。
2. **Set-Contrastive Metric Learning**: 训练一个投射头，学习将候选 rollout 与正负锚点集进行对比的嵌入空间，计算对齐得分（alignment scores）。
3. **Contrastive Advantages**: 将对齐得分作为 advantage 信号，在组内做标准化，然后直接用于 GRPO 风格的策略优化，不使用任何任务 ground-truth verifier。
4. **冻结投射头**: 策略优化阶段冻结 metric 学习的投射头，确保得分稳定。

## 关键结果

| 模型 | 方法 | GSM8K Pass@1 | GSM8K Pass@8 |
|:---|:---|:---:|:---:|
| Qwen2.5-1.5B | Base / Dr.GRPO / RRPO | 0.665 / 0.609 / **0.691** | 0.902 / 0.912 / **0.934** |
| Qwen3-1.7B | Base / Dr.GRPO / RRPO | 0.746 / 0.765 / **0.768** | 0.928 / 0.924 / **0.938** |
| Qwen3-4B | Base / Dr.GRPO / RRPO | 0.868 / **0.903** / 0.870 | 0.944 / **0.958** / **0.958** |

- **SAMSum**: RRPO 在多数指标上获得最优或并列最优结果，而 PSEUDO-SFT 在 1.5B 模型上显著降低性能。
- **ELI5**: RRPO 在所有三个模型上均提升 Mean ROUGE，而 PSEUDO-SFT 只提升了其中一个。
- 学习曲线显示 RRPO 的性能随训练步数稳定提升，证明参考相对 advantage 信号提供了有用的优化方向。

## 亮点

1. **开拓了 GRPO 的应用边界**: 首次将组相对优化扩展到非可验证场景，大幅扩展了适用范围。
2. **方法精美简洁**: 通过条件生成 + 对比学习 + 冻结投射头的组合，实现了一个干净的框架，不需要额外的模型或复杂的训练管线。
3. **小模型反而更受益**: 在 Qwen2.5-1.5B 上 RRPO 显著超越 Dr.GRPO（+8.2% Pass@1），表明弱监督信号对小模型更有效。
4. **与 SFT 互补**: RRPO 在 SFT 初始化之后仍能提供额外提升，说明它与监督微调是互补关系。

## 局限

1. **没有公开代码**: 论文中未提供 GitHub 仓库，复现成本较高。
2. **仅在英语数学、摘要、解释任务上验证**: 未在工具调用、代码生成、多轮交互等 agent 场景上测试。
3. **强模型上优势不明显**: 在 Qwen3-4B 上 RRPO 只是与 Dr.GRPO 持平，说明强模型可能对弱监督信号的敏感度降低。

## 个人评价

这篇论文的想法很干净：用条件生成的高/低质量回答作为参考锚点，学习一个嵌入空间来对比候选回答的质量，然后把这个得分当作 advantage。这实质上是用学习到的测度替代了硬编码的正确性信号，类似于用一个简单的 reward model 来替代可验证反馈。

对于 GWS 项目的启示：在焊缝路径规划任务中，很多时候没有唯一的正确答案（多条路径都可以是优秀的），RRPO 的参考相对方法可能比传统的基于正确/错误的 RL 更合适。可以考虑将这种思路应用到我们的路径规划 agent 训练中。
