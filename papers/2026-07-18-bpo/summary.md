# Branching Policy Optimization: Sandbox-Native Language Agent Reinforcement Learning

**arXiv**: 2607.14171 | **GitHub**: 无 | 机构：MBZUAI & City University of Hong Kong / McGill University

---

## 一句话总结

BPO 利用安入桥的确定性和可快照性，在高犆决策点分叉多条路径并计算同级基线，从而显著降低强化学习中路径采样的方差，在 WebShop/ALFWorld/SWE-bench 上比 GRPO/RLOO 提升 3.6-6.1 绝对百分点。

## 问题背景

当前 LLM agent RL 算法（PPO/RLOO/GRPO）继承了 RLHF 的开发拓扑结构：对每个 prompt 独立采样 N 条完整路径，然后用组基线减弱估计的方差。但这完全忽略了 agent 安入桥的核心特性：它们是确定性的、可快照的、可从任何中间状态恢复的。这一特性在推理时被 Tree-of-Thoughts 等方法广泛使用，但在训练时却被完全忽略。

## 核心方法

- 在一条 backbone 路径上动态识别高犆决策点（指令分布混乱度高的位置），对安入桥进行快照
- 在每个分叉点 fork K 个替代动作，每条分支执行到终止状态，形成一棵共享前缀的上下文树
- 用同级节点的回报计算每步 advantage，代替组垂直的独立路径对比
- 理论证明：该估计器无偏且方差严格小于 GRPO （方差减少量 = 前缀可解释的回报方差部分）
- 训练时只需要少量 full-length 路径 + 大量短分支路径，显著提升计算效率

## 关键结果

| 基准 | 提升 | 对比算法 | 模型 |
|:---|:---|:---|:---|
| WebShop | +3.6 pp | GRPO / RLOO | Qwen2.5-7B, Llama-3.1-8B |
| ALFWorld | +6.1 pp | GRPO / RLOO | Qwen2.5-7B, Llama-3.1-8B |
| SWE-bench Verified | +4.2 pp | GRPO / RLOO | Qwen2.5-7B, Llama-3.1-8B |
| 梯度范数方差 | 减半 | GRPO | - |
| 策略更新效率 | 38% 更少 | GRPO | - |

## 亮点

- 理论上严谨：从安入桥的确定性/可快照性出发，给出了无偏性和方差严格减少的数学证明，这在同类工作中少见
- 实际高效：用 38% 更少的策略更新次数就达到最优基线的性能，显著降低训练成本
- 简洁实现：无需学习批判，在现有开反框架就可实现
- 通用性强：同时覆盖了文本对话、代码、web 三大类任务，证明方法的广泛适用性

## 局限

- 依赖于安入桥的快照能力，对不支持快照的环境（如某些网络 API组合）不适用
- 高犆决策点的识别参数需要手动调整，缺乏自适应机制
- 在很短的任务路径（<5 步）上收益有限，因为分叉的空间太小

## 个人评价

这篇工作很巧妙地把 inference 方法（树搜索）的思想移植到了 RL 训练中，而且理论上很干净地证明了方差减少。这对于当前热门的 GRPO 系列算法是一个直接的改进方向。与其他工作（如级别信用分配、回顾模式等）不同，BPO 从架构层改变了开反的拓扑结构，而非只改变信用分配方式，这意味着它可以和其他改进方法组合使用。唯一可惜的是没有开源代码，但方法本身很简洁，在 verl 等框架上实现应该不难。
