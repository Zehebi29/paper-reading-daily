# EnvACE：通过世界排练内化环境动态的智能体强化学习

**arXiv**: 2608.06197 | **GitHub**: https://github.com/Within-yao/EnvACE | **机构**: 上海交通大学（第一作者，共同一作含浙江大学；腾讯、港中文等合作）

---

## 一句话总结

EnvACE 让智能体策略在训练时自己"扮演环境"生成工具响应（世界排练），把环境动态内化进策略参数，在 BFCL-v4、tau2-Bench、VitaBench、FinMCP-Bench 四个基准上以 32.91% 的总体分超过 EnvScaler-8B 等环境扩展基线，还能在测试时先私下排练再执行真实环境。

## 问题背景

- 训练长程工具使用智能体通常依赖真实或合成的可执行环境，构建和验证成本高，外部模拟器的响应又难以保证准确和一致。
- 现有方法无论用真实环境还是 LLM 模拟器，环境建模都留在策略之外，策略只是被动消费外部提供的观测，导致"行动-响应"关系无法内化。
- 作者想证明：环境响应生成可以成为策略自身的显式角色，让训练彻底摆脱外部环境依赖。

## 核心方法

- **世界排练（World Rehearsal）**：共享策略承担两个角色——行动角色生成工具调用，排练角色紧接着扮演环境生成该调用诱导的响应，后续决策基于自生成的响应，轨迹完全由策略自己展开，不需要查询外部环境。
- **角色级 GRPO（Role-Wise GRPO）**：对同一组 rollouts 按角色分别计算 reward baseline 和 advantage，两个角色的输出共同更新共享参数，端到端用任务成功奖励优化。
- **测试时扩展**：推理时策略先进行 N 次私有排练（并行模式各自独立想象、顺序模式让后续排练看到前次轨迹和修订建议），汇总成排练记忆后引导一次真实环境提交执行，排练本身不触碰外部环境。
- 训练配置：Qwen3-8B 主干 + CM2 数据集，470 步、batch 16、每 prompt 4 个 rollout，Qwen3-30B-A3B 做 LLM judge。

## 关键结果

| 基准 | EnvACE-8B | 最佳基线对比 |
|:---|:---|:---|
| 总体 Overall（三基准均值） | **32.91%** | EnvScaler-8B 31.92%（+0.99）、AWM-14B 32.54%（+0.37） |
| BFCL-v4 Avg | 46.04% | 超 Qwen3-8B +2.00、AWM-8B +1.75，距 EnvScaler-8B 47.07% 差 1.03 |
| tau2-Bench Avg | **36.7%**（第二高） | 超 EnvScaler-8B +3.8、AWM-8B +5.5、AWM-14B +6.0 |
| VitaBench Avg | **16.0%**（7B-8B 中最佳） | 超 EnvScaler-8B +0.2、ScaleEnv-8B +1.0 |
| FinMCP-Bench TF1 | **46.78%** | 超 EnvScaler-8B +3.10、AWM-8B +4.28；TP 54.04% 全场最高 |

- **消融 vs 标准 GRPO**：tau2-Bench 从 31.2% 提升到 36.7%（+5.5%）。
- **参数共享消融**：行动与排练分开策略只有 35.5%，共享参数到 36.7%（+1.2%），支持"内化"假设。
- **模型规模**：1.7B→8B 时 BFCL-v4 从 31.81%→46.04%（+14.23%），tau2-Bench 从 15.3%→36.7%（+21.4%）。
- **测试时排练（N=2）**：并行排练总体 36.7%→40.9%（+4.2%）；用 base 模型排练只到 36.8%，说明增益来自内化的环境知识而非单纯推理算力；N=1→2 提升，N=3 因上下文过长回落。

## 亮点

- 思路干净：把环境模拟从独立模块变成策略的角色，训练完全不需要外部环境，直接绕开环境合成与验证的成本瓶颈。
- 角色级 advantage 分离是个实用技巧，解决了"行动和排练共用一个轨迹奖励"时的 credit assignment 模糊问题。
- 测试时"先私下排练、再提交执行"在不增加外部交互的前提下获得稳定增益，对真实部署场景友好（不污染环境、可提前规避无效调用）。
- 代码开源（github.com/Within-yao/EnvACE），结果跨四个异构基准验证，不是单一环境上的过拟合。

## 局限

- 只评估到 8B 规模，更大模型上世界排练是否持续有效未验证（作者自述）。
- 评估聚焦工具交互任务，GUI、编码等更广 agentic 场景未覆盖。
- 排练响应由策略自生成，如果训练数据里环境响应分布有偏，排练可能"自欺"——论文没有系统分析排练响应与真实环境的分布差距。

## 个人评价

这篇最戳我的点是"环境也可以被参数化进策略"这个视角。之前 PaW（06-23）是把世界建模作为辅助目标协同训练，Qwen-AgentWorld 是独立语言世界模型，而 EnvACE 更进一步：排练不是辅助信号，而是 on-policy 轨迹本身的一部分，环境响应直接参与优势计算。这种"先想后做"的架构和工业场景天然契合——真实执行有成本有风险，先让模型在脑子里把工具调用过一遍，比直接上真环境试错安全得多。

另一个值得借鉴的细节是 role-wise GRPO：同一个共享策略干两件事，reward 却按角色分开 normalize。这本质上是给"演员"和"裁判"各自一把尺子，防止裁判角色被演员的稀疏成功信号带偏。如果后面做 agent 相关训练，这个"多角色共享策略 + 角色级 advantage"的模板可以直接复用。

测试时排练的收益曲线（N=2 最佳、N=3 回落）也提醒我们：world rehearsal 不是越多越好，记忆压缩和上下文预算才是瓶颈——这和长上下文 agent 的普遍痛点是一致的。
