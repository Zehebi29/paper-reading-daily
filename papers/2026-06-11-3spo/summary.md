# 3SPO: State-Score-Supervised Policy Optimization for LLM Agents

**arXiv**: 2606.09961 | **GitHub**: https://github.com/genalyu/3SPO | **机构**: Tsinghua University (Yu Han, Kailing Li, Yang Jiao, Yulin Dai, Yuqian Fu)

---

## 一句话总结

3SPO 将 Agent RL 从轨迹级优化推进到步级优化，通过动态状态评分实现逐步信用分配和自适应 rollout，在 ALFWorld 上比 GRPO 提升 22.6%，收敛速度快 1.8 倍。

## 问题背景

现有 RL 算法（GRPO、PPO 等）在多轮 Agent 任务中以完整轨迹为单位做策略优化，只有轨迹结束时才有奖励信号。这导致三个问题：(1) 稀疏延迟的奖励使得中间步骤的信用分配极其困难；(2) 错误决策会在后续步骤中传播，直到轨迹结束才收到纠正信号；(3) 所有步骤被均匀对待，无法聚焦计算资源到真正困难的状态。

## 核心方法

- **动态状态评分 S(s_t)**: 基于历史交互统计计算每个状态的难度分数。成功率低的状态获得高分（更有学习价值），已解决的状态获得低分（可以跳过），过于困难的状态直接归零（截断探索避免浪费）
- **步级奖励模型 R_3SPO**: 将稀疏的轨迹奖励拆解为三部分——新奇奖励（鼓励状态变化，防止重复循环）、状态评分差（从难到易的转移获得正奖励）、终端任务奖励。三者的权重随访问次数自适应调整
- **自适应 rollout + 步级策略优化**: 根据状态分数动态分配 rollout 数量，高分（未解决）状态分配更多 rollout，低分状态直接跳过。每步完成后立即做 PPO 风格的策略更新，而非等到轨迹结束
- **Ranked Backtracking DFS**: 优先探索高奖励分支，然后系统性地回溯探索替代路径

## 关键结果

| 指标 | 3SPO vs GRPO |
|------|-------------|
| ALFWorld 成功率 | +22.6% |
| WebShop 分数 | +15.6 points |
| 状态探索量 | 2.4x more |
| 收敛速度 | 1.8x faster |

- 基座模型: Qwen2.5-1.5B/7B-Instruct
- 对比基线: GPT-4o, Gemini-2.5-Pro, ReAct, Reflexion, PPO, RLOO, GRPO, GiGPO, HGPO
- 在 ALFWorld 上 3SPO 达到接近 97% 的成功率，显著快于所有基线
- 理论保证: 在 per-state bandit 抽象下，分配遗憾为 O(log I)，达到对数最优

## 亮点

- 从轨迹级到步级的范式转变，直击多轮 Agent RL 的信用分配痛点
- 状态评分函数设计精巧，同时编码了难度、探索价值和截断条件
- 自适应 rollout 机制让计算资源自然流向最有学习价值的状态
- 有理论分析（对数分配遗憾），不只是经验性的工程改进

## 局限

- 实验只在 ALFWorld 和 WebShop 两个 benchmark 上验证，缺少更复杂的 Agent 任务（如 SWE-bench、WebArena）
- 状态评分依赖历史交互统计，冷启动阶段的效果未详细讨论
- 基座模型规模较小（1.5B/7B），大规模模型上的表现未知

## 个人评价

3SPO 的核心洞察很有价值: 在多轮 Agent 任务中，不同步骤的学习价值差异巨大，但现有方法把它们一视同仁。这个思路和 TRACE (2606.11119) 的 rollout 预算分配有异曲同工之处，但 3SPO 更进一步，在每一步都做决策而非只在 prompt 根节点分配。状态评分函数的设计特别有意思——它同时编码了"这个状态有多难"和"这个状态值不值得继续探索"两个信号。对于关注 Agent RL 训练效率的研究者来说，这篇论文值得仔细读，尤其是状态评分和自适应 rollout 的实现细节。
