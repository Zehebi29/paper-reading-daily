# PATS: Policy-Aware Training Scaffolding for Agentic Reinforcement Learning

**arXiv**: 2607.21419 | **GitHub**: 无 | **机构**: 未公开

---

## 一句话总结

PATS 提出了一种“策略中心”的训练脚手架范式，将技能重新定义为动态的训练支撑工具，在 ALFWorld/WebShop 上比强基线提升了 18.6%，同时减少了 32.1% 的 prompt token 消耗。

## 问题背景

在长距离 LLM Agent 强化学习中，弱策略经常重复相同的失败，产生无信息量的滚动轨迹，限制了策略优化。现有技能中心方法（如 skill optimization/filtering/internalization）仍然围绕技能本身，而非设计为适应性的训练时支撑。这导致对演进中的策略缺乏针对性帮助，特别是当策略很弱时。

## 核心方法

1. **证据卡机制**：将最新策略的滚动轨迹组转换为“证据卡”（evidence cards），捕获成功策略和失败模式

2. **任务特定评估**：使用任务特定的评估机制来调整后续滚动中的 context，为弱策略提供具体的指导

3. **动态脚手架调整**：随着策略提升，自动修正或删除多余的 context，减少对显式指导的依赖，保留有用的滚动差异

4. **标准 RLVR 优化**：使用环境奖励进行标准的可验证奖励强化学习（RLVR）

5. **推理时不带脚手架**：训练脚手架在部署时完全丢弃，不影响推理时的效率

## 关键结果

| 基准 | PATS | 强基线 | 提升 |
|:-------|:----:|:----------:|:--------:|
| ALFWorld | +18.6% | 最强基线 | 显著 |
| WebShop | +18.6% | 最强基线 | 显著 |
| 搜索QA (7个基准) | 竞争力相当 | 强基线 | 少用 32.1% prompt tokens |

## 亮点

1. **策略中心思维转变**：从“技能中心”转变为“策略中心”，技能被重新定义为动态训练支撑工具，而非终点目标

2. **动态适应性**：脚手架随策略强度自动调整，“弱时多帮、强时少帮”，符合教学的 scaffolding 退场原理

3. **推理时零开销**：脚手架在部署时完全丢弃，不影响推理时间和成本

4. **Token 效率**：在保持竞争力的同时减少 32.1% 的 prompt token 消耗

## 局限

1. **没有开源代码**：论文未提供 GitHub 链接，无法复现实验结果

2. **实验范围有限**：主要在 ALFWorld/WebShop 和搜索 QA 上验证，未涉及更复杂的现实场景（如代码生成、多模态）

3. **证据卡质量依赖**：脚手架的有效性取决于证据卡的质量，若弱策略完全无法产生有效轨迹则可能难以启动

## 个人评价

PATS 的核心觉得很有意思：把技能从“学习目标”变成“教学工具”。这类似于 human pedagogy 中的 scaffolding 退场策略——当学生还很弱时给予大量支持，随着能力提升逐渐减少帮助。这个思路在 agentic RL 领域比较新颖，以前的工作都是在优化技能本身的质量，而不是把技能当作训练辅助。

另外，PATS 在推理时丢弃脚手架这个设计很巧妙——它解决了许多技能优化方法的通病：技能层的复杂性在推理时也会带来额外开销。不过没有开源代码让人有点可惜，希望后续能补上。

对我的启发：在设计 GWS 或其他 agent 系统时，可以考虑“训练时帮助”和“推理时纯净”的双重设计思路，这在工程上很有实用价值。
